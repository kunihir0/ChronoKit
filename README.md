# ChronoKit

ChronoKit is an enhancement tweak for TikTok providing video downloading, anonymous viewing, ad blocking, and customizable feed experiences. It integrates natively with the iOS environment and provides a secure, encrypted vault for downloaded media.

## Support

* TikTok 46.6.0
* iOS 15.4
* Rootless / Dopamine
* RootHide

## Installation

**APT Repository**

Add the following URL to Sileo or Zebra to install ChronoKit:

`https://kunihir0.github.io/ChronoKit/`

The repository automatically provides the correct version (Rootless or RootHide) based on your jailbreak architecture.

**Direct Download**

You can also download the `.deb` files directly from the [Releases](https://github.com/kunihir0/ChronoKit/releases) page. Ensure you download the correct variant:
- `_rootless_iphoneos-arm64.deb` for Rootless (Dopamine).
- `_roothide_iphoneos-arm64e.deb` for RootHide.

## Sideloaded / Injected IPA

An injected IPA build may be supplied through Releases or the repository workflows where permitted. Alternatively, users can utilize the provided GitHub Actions workflow (`Inject IPA`) using their own authorized, decrypted TikTok 46.6.0 IPA. 

Please note that no decrypted TikTok applications are hosted or provided in this repository. Injected applications must be installed using tools like TrollStore or SideStore.
